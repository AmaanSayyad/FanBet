- **UserManagement.mo:** Handles user registration, authentication, and balance management.

- **QuizManagement.mo:** Manages the creation and status of quizzes.

- **Betting.mo:** Allows users to place bets and keeps track of all bets.

- **BetResolution.mo:** Resolves bets based on quiz outcomes and distributes rewards.

- **TokenManagement.mo:** Handles deposit, withdrawal, and balance inquiries.
